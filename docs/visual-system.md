# 近未来实验室 · v0.16.0

默认使用深空蓝，提供轨道白阅读主题。已有访客的主题选择继续保留；主题、语言和动效开关彼此独立。

| 角色 | 深空蓝 | 轨道白 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | `#080F1F` | `#EFF4FC` | 统一空间底色 |
| 内容面板 | `#101C30` | `#FFFFFF` | 正文、展品与新闻 |
| 次级面板 | `#172A43` | `#E5EDFA` | 讲解、选项分组 |
| 正文 | `#EAF2FF` | `#172940` | 主要信息 |
| 辅助文字 | `#A3B3CE` | `#526581` | 说明与来源 |
| 操作 | `#79A5FF` | `#2855D9` | 链接、控件、当前页 |
| 数据信号 | `#69DFF1` | `#087B90` | 数据流、机制、检查结果 |
| 人与历史 | `#FFC58C` | `#985123` | 历史、人工判断、对照信息 |

技术标题采用各语言的本地无衬线字体。历史介绍与结语保留衬线标题。正文不叠加网格、光束或移动粒子；这些元素只存在于图形区域。

序厅采用透明切片与连续信息路径。积累模式留下与尝试次数对应的节点，汇流模式可关闭输入通路，碰撞模式区分直接交付与检查退回。文本和控制位于动效区之外。画布仅绘制固定投影与少量信号，限制像素密度，不逐帧改写页面结构或使用发光模糊滤镜。

控件反馈约 180 ms，图表数值变化约 300 ms；结语光束以 18–24 秒缓慢漂移，并用渐变和遮罩柔化边缘。保留全局暂停和系统减少动态效果设置。历史插画不改写为科幻画面，通过面板和注释统一视觉。

主主题位于 `src/future.css`；旧馆藏工具使用 `src/future-archive.css`。构建时追加样式，原始馆藏正文与交互不变。无新增字体、框架、外部视觉服务或运行时依赖。

验证入口：`tests/future-theme.html` 检查两套主题、八语言、全站路由与主要控件对比度；`tests/usability-feedback.html` 检查展品交互、裁切和暂停。两者应依次运行。
